
# URL Shortener Service

Микросервис на Go для создания и управления сокращенными ссылками.

## Функциональные возможности

- **Сокращение URL**: Генерация уникальной ссылки длиной ровно 10 символов.
- **Алфавит**: `[a-zA-Z0-9_]` (Base63).
- **Идемпотентность**: Один оригинальный URL всегда соответствует одной сокращенной ссылке.
- **Хранение данных**: Поддержка двух типов хранилищ (PostgreSQL и In-Memory).
- **Конкурентность**: Потокобезопасная работа при высоких нагрузках.

## Технологический стек

- **Language**: Go 1.26
- **Framework**: chi (HTTP Router)
- **Database**: PostgreSQL 15 / In-Memory (custom implementation)
- **Migration**: goose
- **Containerization**: Docker, Docker Compose

## Архитектура проекта

Проект реализован согласно принципам **Clean Architecture**:
- `/cmd`: Точка входа в приложение.
- `/internal/entity`: Бизнес-объекты и ошибки.
- `/internal/usecase`: Бизнес-логика (генерация и валидация).
- `/internal/repository`: Реализация хранилищ (Postgres, In-Memory).
- `/internal/transport/http`: HTTP-хендлеры.
- `/pkg`: Вспомогательные пакеты (base63, storage).

## Запуск проекта

### 1. Использование Docker Compose (рекомендуется)
Сборка и запуск сервиса вместе с базой данных:
```bash
make docker-up
```

### 2. Локальный запуск
Для работы с Postgres необходимо настроить переменные окружения в `.env` файле, после чего:
```bash
make run
```

### 3. Переключение хранилища
Тип хранилища определяется переменной окружения `STORAGE_TYPE` (`postgres` или `memory`). По умолчанию в `docker-compose.yml` установлено `memory`.

## API Методы

### Создать сокращенную ссылку
- **URL**: `POST /`
- **Body**: `{"url": "https://example.com"}`
- **Success**: `201 Created`, `{"result": "baaaaaaaaa"}`

### Получить оригинальный URL
- **URL**: `GET /{id}`
- **Success**: `307 Temporary Redirect` (Location header)
- **Error**: `404 Not Found`

## Тестирование
Запуск всех unit-тестов с проверкой покрытия:
```bash
make test
```

## Алгоритм генерации
Сервис использует инкрементальный числовой ID, преобразуемый в систему счисления Base63. Для обеспечения фиксированной длины (10 символов) используется дополнение (padding) нулевым символом алфавита. Это гарантирует отсутствие коллизий и высокую скорость работы.
